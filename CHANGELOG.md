## [1.0.0] - 2026-02-13

### Added
- Initial public release
- Layout utilities (flex, grid, display)
- Spacing utilities (margin, padding)
- Typography utilities (font, text alignment, text transform)
- Color utilities (background, text, border)
- Border utilities (width, style, radius)
- Sizing utilities (width, height, max-width)
- Effect utilities (opacity, shadow)
- Position utilities
- Overflow utilities
- Responsive modifiers for all utilities
- State modifiers (hover, focus, active)
- Design token system
- Sass customization support
- Complete documentation
- HTML examples
